    Как считаем

    Тесты · индекс Epoch AI

    Epoch Capabilities Index сводит десятки сложных тестов (математика, код, наука, рассуждения) в одну шкалу. Чем выше, тем сильнее модель. Рядом с числом — погрешность: близкие значения стоит считать ничьей.

    epoch.ai/benchmarks

    Люди · Arena

    Люди задают вопрос, видят ответы двух неизвестных моделей и выбирают лучший. Из сотен тысяч голосов считается рейтинг Elo. Берём вариант с поправкой на стиль: длинный и нарядный ответ не получает бонуса. Есть отдельные зачёты по русскому языку, математике, коду, сайтам и картинкам.

    arena.ai

    Цены · OpenRouter

    Цена API в долларах за миллион токенов: это примерно 700 тысяч русских слов. Для сравнения берём смесь 3 : 1 — три части входа на одну часть выхода. В чат-приложениях с подпиской цены другие.

    openrouter.ai/models

    Физика, математика, наука, факты

    Отдельные тесты из архива Epoch AI: CritPt — задачи уровня научной работы по физике, FrontierMath — новые задачи от математиков, GPQA Diamond — вопросы по естественным наукам уровня аспиранта, SimpleQA Verified — короткие вопросы о фактах (как часто модель выдумывает). Балл — доля верных ответов. У CritPt погрешность не публикуется.

    epoch.ai/benchmarks

    Проверка ЕГЭ — наш зачёт

    Модель проверяет решения второй части ЕГЭ по физике (21–26) по критериям ФИПИ, а мы сравниваем её балл с баллом эксперта. Публикуем только сводные цифры, без работ. Это пилот: замерены две модели, и регламент проверки настраивался на Claude Opus 5.5 — другим моделям он может подходить хуже. Погрешность — 95 % интервал для доли совпадений.

    Ничья или отрыв

    Проценты от самого Elo ничего не значат: важна разница в очках. Разница 20 очков — лидера выбирают в 53 сравнениях из 100, 50 очков — в 57, 100 очков — в 64. Если интервалы погрешности двух моделей пересекаются, это ничья при любой разнице. Отрыв — интервалы не пересекаются, явный отрыв — от 50 очков Elo (или от 5 пунктов индекса Epoch).

    Какие зачёты показываем

    В каждом общем зачёте и подборке за выбранный период должны участвовать актуальные Claude, GPT и Gemini. Поколение определяем по старшему номеру версии в каталоге, для Claude — отдельно по линейкам Opus, Sonnet, Haiku и Fable. Место участника может быть любым. В парном сравнении доступны и замеры с меньшим числом участников.

    Актуальные модели

    По умолчанию показываем модели, вышедшие за последние 12 месяцев: старые почти никогда не попадают в верх рейтингов, а графики с ними загромождены. В шапке можно выбрать срок — 1, 3, 6, 12 месяцев или все модели. Дата выхода — из Epoch, иначе из OpenRouter, иначе день первого появления модели в Arena (в таблице с пометкой «≈»).

    Режимы и названия

    У многих моделей есть режимы «думать дольше» (High, Max). Для каждой модели показываем лучший режим. Названия из разных источников сводятся автоматически, сложные случаи — вручную. Модели, которых нет в источнике, показаны с прочерком.

    Подбор под задачу

    Каждый рейтинг переводим в шкалу от 0 до 100: лучшая модель — 100, слабые — около нуля. Потом складываем с весами задачи. Если у модели нет главного для задачи рейтинга, в подборку она не попадает.

    Чего здесь нет

    Российских моделей (GigaChat, YandexGPT) в этих открытых рейтингах нет — их там просто не тестируют. Доступность из России и оплата российской картой тоже не учитываются.
